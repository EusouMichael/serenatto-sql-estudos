# Scripts SQL

Os scripts estão separados por etapa do estudo:

1. **Modelagem** — criação das tabelas e regras de integridade.
2. **Carga de dados** — inserções da base.
3. **Consultas** — filtros, agregações, JOINs, subconsultas e operações de conjunto.
4. **Views** — criação e consulta de views.
5. **Triggers** — automação do cálculo de faturamento diário.
6. **Atualizações e transações** — PRAGMA, UPDATE, DELETE e exercícios relacionados a transações.
